Conditional interaction: source and native comparison
2026-10-28

The source theory now includes absence of a complete source query. A query's
local bindings do not reach the following sources. Its successful absence row
retains observations of the regions needed to establish that no row exists.
This includes empty queries, nested absence, pure computed sources, and every.

Example: a space contains (msg a) and (ack b). Each pattern has a match, but
(read (msg $x)) followed by (read (ack $x)) has no joined row. Its absence
therefore succeeds. Adding (ack a) disables that absence.

Native comparison
-----------------
Run interaction-conditions.metta with the Prime dialect. The correlated-query
examples agree with the source calculation. The experiment intentionally also
retains unresolved cases; it is not an all-passing conformance fixture.

The source-form classifier now recognizes the empty conjunction, let and every.
An explicitly supplied location still selects literal-pattern absence, including
patterns whose heads happen to be source operators.

Open findings:

1. Native absence flattens every into candidate rows. With no candidates it
   reports absence. The source every has one amalgamated row even when its
   contributing set is empty, so an enclosing absence is false there.
2. A computed source inside native absence is currently stuck. Standalone let
   is now classified as a source, so it no longer falsely establishes absence
   by searching for a stored atom shaped like the computation.

The native adaptive scan may retain fewer regions than the source's conservative
completeness footprint. Its correspondence needs the actual adaptive read history;
the source's footprint theorem does not by itself prove that implementation.

No default notation or universal operational-to-conversion rule is selected.
Successful checking of a rule still requires its selected theory and evidence.
