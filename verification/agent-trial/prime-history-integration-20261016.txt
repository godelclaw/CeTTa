Recorded agent comparison
-------------------------
All 92 historical task projections and 414 recorded turns agree with the
current agent engine. Effects are deterministic shadows; historical commands
are not executed again. The recordings remain private.

One paired 414-turn run consumes 130.89 CPU seconds on the current engine
and 129.80 on the merged engine, with 729.2/730.9 MiB peak RSS. This supports
approximate parity for that workload. It is not a statistical speed claim.

Two larger Prime cases show workload-dependent timings in single pairs:
the game corpus takes about 68/65 CPU seconds and Hopper about 48/53 CPU
seconds, parent/merged respectively. Both pairs retain exact outputs; Hopper
uses about 1.93 GiB peak RSS on each engine. These timings do not establish
general performance bounds.
